# drinksapp.co.za

The DRINKS website, served by GitHub Pages at https://drinksapp.co.za.

- `index.html`: home page
- `app/index.html`: download page (the QR code opens this). Fill in the App Store and Google Play links at the
  top of the page once the app is published.
- `CNAME`: the custom domain. Don't delete it.

The app code lives in the private `drinks-app` repository; a copy of these files is kept in its `website/` folder.
